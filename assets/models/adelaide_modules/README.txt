第二轮第五天 / 阿德莱德通用建筑
六类：台阶式办公楼、板式商业楼、砖石沿街楼、玻璃幕墙塔楼、工业厂房、公共设施楼。
六类完成通用立面与屋顶；当前48栋精修，每类8栋，三个连续片区各16栋。
原型：prototypes/style_0.tscn 到 style_5.tscn，统一展示尺寸260×320×220m，每类含LOD0/1/2三个可编辑MeshInstance。普通ArrayMesh资源可直接预览；不把原型拉伸套在城市上。
运行生成：scripts/world/adelaide_building_mesh.gd 按实际地块宽深和高度重新排布模块；楼层6.4m、窗格10/12/14m，材质3/3/2m平铺；UV、UV2、正向法线和切线齐备。
当前48栋：selection.json 和 adelaide_building_library.gd::TARGETS。每类8栋，来自既有低空路线5000m以内的完好地块。默认不替换61栋受损建筑。
碰撞：旧地块/原碰撞保持；主盒子显示停止生成；带碰撞的原屋顶箱体保留可见外观。新增细节不添加碰撞。屋顶新模块位于原 footprint 内。
LOD：高档近景最多6栋LOD0；中档最多LOD1；低档LOD2。依据包围盒边缘距离、屏幕高度、视锥和阈值缓冲选择。0.35秒互补不透明抖动掩码过渡，无透明排序。
阴影：每栋楼的完整近景几何合并为单表面阴影专用网格；可见LOD关闭重复投影，保持阴影轮廓并减少材质阴影绘制。
材质：共享 concrete_wall_003 / brick_wall_001 / painted_metal_shutter 2K PBR + 八条原创建筑收边图集；玻璃保持不透明。法线RG重建Z。纹理和玻璃细格按像素尺寸和距离过滤。
选择复现：BuildingLibrary.choose(current_parcel_records)；只读地块不调用城市随机数。修改线路/城市布局后重新烘焙TARGETS并跑保护检查。
精修模型开关：新建地图前设置 city.building_modules_enabled=false；此开关仅停用精修模型，全城共享材质仍启用。外部 parcel_visual_factory 仍优先，可替换自定义模型。完整回退使用第五天独立backup恢复脚本/着色器/目录。
限制：保留原有游戏地图尺度，主体高度和地块未缩小；全城材质推广与后三类补齐已完成，机库/节庆中心精修属于第六天。
