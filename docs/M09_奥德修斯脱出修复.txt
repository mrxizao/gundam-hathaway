M09 精确防御：奥德修斯脱出修复
2026-10-16

原因：第三章通用关卡生成器附加了hp<0.01即end:lose的触发器。
佩涅罗佩本体达到脱出血线后仍然alive=true，但其本体血量低于1%，
关卡触发器会立即进入失败结算，导致脱出后的核心无法正常继续任务。
原机体数据仍然保留脱出，并非M04的敌机规则污染了玩家机体。

修复：M09使用独立的胜利触发器，不继承基于本体血量比例的提前失败触发器。
真正的玩家机destroyed信号及Game判负流程保留。
本体达到脱出血线或被一击打空后，进入奥德修斯形态，以自己的满血条继续作战。
奥德修斯核心被击毁后才进入失败结算。
M04敌方佩涅罗佩仍然不脱出，主机体血量归零直接爆炸并结束关卡。
其他关卡数据、M09出击演出、台词、音乐及胜利目标保留。

验证：
修复前同一运行测试：18 PASS / 10 FAIL，稳定复现壳体受损即提前失败。
修复后suite_m09_core_escape：28 PASS / 0 FAIL。
M04不脱出反例suite_m04_no_escape：26 PASS / 0 FAIL。
第三章规则与存档suite_chapter_three：116 PASS / 0 FAIL。
本次为相关套件定向回归，总计170 PASS / 0 FAIL，不代表全工程完整回归。
GPU实际模型验证通过：壳体打空后成功显示奥德修斯并保留战斗HUD；
随后核心被击毁才显示MISSION FAILED。
探针：tools/m09_core_escape_preview.tscn。

在正在运行的游戏中，旧Mission实例可能保留旧触发器，请重启游戏后进入M09。
