# 启动影片加载与流畅性优化 · 2026-10-09

## 玩家可见的变化

- 启动先进入轻量开场播放器，在影片播放期间异步读取主程序资源，并分阶段生成主菜单背景。保留原有 80% / 20% 选片比例。
- 未完成加载时吞掉跳过输入；完成后显示“加载完成 · 按任意键跳过”。键盘、鼠标按钮、手柄按钮均支持；长按键的重复事件和手柄摇杆漂移不会跳过。
- 影片先播完则继续显示加载状态，完成后进入主菜单。影片不存在、无头运行或明确使用 `--skip-intro` 时显示普通启动读条。
- 出击复用读条期间生成的地图，取消进入战斗时的第二次建图；读条淡出完成后才开始战斗。
- 暂停菜单退回主菜单、战斗结算返回主菜单时显示读条。城市地形、街区、道路生成增加分帧让出和阶段进度。

## 性能与稳定性

- AI 目标选择约每 0.2 秒扫描一次，并错开扫描时间。目标失效、被主动清空、场上机体数量变化或演出指定新目标时立即响应；飞行、安全检查和武器逻辑继续逐物理帧执行。
- 3D 仪表及仪表纹理按 30 Hz 更新，隐藏时停止渲染；全周天 HUD 和相机同步仍逐帧执行。
- 默认场景 MSAA 从 8x 调整为 2x，仪表 3D 视口从 4x 调整为 2x，以降低渲染成本。
- 城市地形在生成平滑法线后建立索引，复用相同顶点，保持三角形、颜色及地形形状。
- 启动时写入 `user://startup.pending`，完成准备后删除。如果上次启动被中断，下次尝试稳定模式：省去影片、关闭 MSAA / SSAO / 卡通后处理。也支持 `-- --safe-mode`。这些更改不主动保存到玩家设置。
- 每个启动阶段写入并刷新 `user://startup_diagnostics.log`，包括渲染方式和显卡名称，方便定位闪退发生的位置。当前工程默认位于 `%APPDATA%/Godot/app_userdata/Mobile Suit GUNDAM·Hathaway/startup_diagnostics.log`。正常关闭窗口会清理启动标记。
